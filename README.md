# Terminal Sudoku

A simple Sudoku game that runs in the terminal. It displays a grid with rows and columns and lets you enter numbers into cells. The game checks whether each move is legal and provides a command to exit whenever you like.

## Features

- Sudoku grid displayed in the terminal
- Enter a number into a cell using a simple command
- Check whether a move is valid
- Exit the game at any time

## Getting started

Run the game using a c compiler (gcc, clang for example) and follow the commands given to you by the programm to set nummbers into the rows.

## How to play

Start the game, choose a cell and row, and enter a number. The game will tell you whether the move is valid or not. Use the exit command when you want to quit.
